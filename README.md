# منتجاتي — ملفات التحميل

هذا المستودع مخصص لملفات التوزيع النهائية لتطبيق منتجاتي.

## الإصدار 1.0.23 (Android build 24)

- **Android:** نزّل ملف APK وثبّته على Android 7.0 أو أحدث. قد تحتاج إلى السماح بالتثبيت من هذا المصدر.
- **Windows x64:** نزّل ملف SETUP ZIP، فك الضغط، ثم شغّل `Install-Montajati.cmd`. يتضمن الحزمة برنامج Microsoft Visual C++ Runtime.
- اسمح للتطبيق بالاتصال على الشبكات الخاصة في Windows Firewall لاستخدام مزامنة الشبكة المحلية.

ميزات OCR من الكاميرا، استقبال المشاركات من تطبيقات Android، وخزنة SAF وWi-Fi Direct خاصة بإصدار Android. مزامنة LAN متاحة على Android وWindows.

**ملاحظة Windows:** ملف التطبيق غير موقّع بشهادة ناشر Windows حتى الآن، لذلك قد يعرض Windows تحذير ناشر عند التشغيل.
